# Personal Portfolio

## Go live on GitHub Pages
1. Create a repository (e.g. `yourusername.github.io`).
2. Upload everything in this folder (keep `index.html` at the top level).
3. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Your site appears at `https://yourusername.github.io/` in a minute or two.

## Customize
- Replace "Your Name", university, links and email (search `your.email@example.com` and `yourusername`).
- Photo: add your picture as `assets/profile.jpg`, then change `assets/profile.svg` to `assets/profile.jpg` in `index.html`.
- Skill bars: edit `data-w` values (0-100) in `index.html`.
- Palette lives at the top of `css/style.css`.
